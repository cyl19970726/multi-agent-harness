Show the proposed roster, roles, providers, Workspaces, owned paths,
completion standards, and permission ceilings. The Host is Team Lead, not an
implicit MemberRun. Teams are durable and are created without any Mission;
Mission/Wave writes are retired and historical rows are Legacy read-only.
Start from shared Works with observable completion criteria and report the
exact Dashboard deep link. Use TeamMessage only for optional Work-linked
conversation. Member-side behavior is defined by
`[[collaborate-as-agent-team-member]]`.
