This slice preserves the approved Company OS warm editorial workbench and the
V4 Standing Agent workspace. It does not redesign the product. It closes the
highest-risk dogfood gaps:

- AgentOS hierarchy and durable Agent identity are visible and navigable;
- Work and Docs links preserve Company, Execution Space, and Project Binding;
- selected records show only their native relations;
- disabled actions look disabled, while enabled actions have a governed
  transport;
- each page exposes the next relevant Docs, Work, or Org relation without
  forcing one global process order.

Raw browser evidence is local and ignored under `.visual-evidence/`. Approved
Expected assets and selected comparisons will be stored beside this contract.
The machine contract must never name an implementation capture that is absent
from the evidence directory; an uncaptured case remains explicitly `null`.
