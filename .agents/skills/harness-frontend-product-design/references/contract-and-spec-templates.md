# Contract & Spec Templates · 合同与规格模板

Phase 0（文字合同）与 Phase 2（测量规格）的直接可用模板。填不满的章节就是没想清楚——
**模板留白处即是流程闸门口**。

## 1. 产品合同模板（Phase 0 产出，存设计真源页）

```markdown
# <模块名> · 产品合同 v<N>

## 能力与用户
- 目标用户 / 触发场景：
- 要完成的 job / 决策 / 结果：
- 成功度量 / 不可接受的失败：
（禁止从"做个 dashboard / 加个详情页 / 复用这些卡片"开始——那是解，不是题）

## 范围与非目标
- 做：…
- 不做（显式）：…

## Journey 映射
actor + 触发 → 当前问题/任务 → 所需信息与权限 → 动作/决策 → 系统响应 → 下一步/恢复/完成
（每条 journey 一段；含主成功、首次使用、中断、无数据、权限、失败恢复——按相关性取舍）

## Surface 清单与正当性
每个 surface 一行：
| id | 回答的首要问题 | 为何必须独立存在 | 入口/返回 | coverage |
coverage 枚举：designed（有待做设计）/ pattern（套已批准模式）/
existing-accepted（沿用已通过验收的现有面）/ excluded（写明理由与批准人）
判定问句：它回答的问题是否变了？沿用现有面是否增加导航/认知成本？
——"旧应用就有""组件已存在""别人家都有"不是理由。

## 数据可见性与权限规则
谁能看到什么；结构性 absent（不是隐藏）；隐私/权限边界。

## 布局合同
栏结构与宽度比、滚动归属、sticky 元素、首视口必须可见的内容、响应式变换。

## UX 行为规则
权威写/假成功禁止、stale/error/loading 行为、危险动作确认、键盘与焦点、文案语调。

## 元素 → 数据映射表（诚实边界）
| 元素 | 出身：数据有出处(字段名) / 静态文案 / needs-backend | 备注 |
needs-backend 项 → 复制到下方立项区。

## needs-backend 立项区（可追踪）
| 工作项 | 需要的投影/字段 | 阻塞的 surface/元素 | 状态 |
```

## 2. Visual Spec 模板（Phase 2 产出，测量得出，版本递增）

```markdown
# Visual Spec v<X.Y> — <模块名>

真源：<冻结设计图位置（Notion 页/文件路径+hash）>。测量脚本：<仓内脚本路径>。
本文件数值标注 [实测]（采样/量距）或 [推导]（真源未展示，按信条推）。

## 0. 信条（美术第一性，全部推导项不得违反）
例：平面为主；分隔=留白>发丝线>极浅填充；强调色仅主动作；无投影/渐变/粗边框

## 1. 调色板（实测表）
| 角色 | 值 | 出处（采样坐标/区域） |

## 2. 字阶（实测表）
| 层级 | size/weight/color | 用途 |

## 3. 几何（实测表，标注基准宽度与等比规则）
栏宽 / 卡片 padding / 行节奏 / 圆角 / icon 尺寸

## 4. 组件形态逐条
每组件：结构 + default/hover/focus/selected/disabled/empty/loading 全状态。
真源未展示的状态标 [推导]。

## 5. 明确不做
无数据字段的元素（转入合同 needs-backend 立项区，不伪造）。
```

## 3. 组件登记表模板（registry，防实现分叉）

存放：**仓内**（如 `docs/frontend/component-registry.md`），因为新建 primitive 的是
写代码的 agent，查表动作必须零成本。

```markdown
| 组件 | 用途 | 何时复用 | 何时允许新增 | 调用点 |
```

规则：新建 primitive 前必查；同一需求的第二个实现出现 = 分叉信号，先合并再继续；
改共享件要查全部调用点。

## 4. 小工件存放位置（统一约定）

| 工件 | 存放 |
|---|---|
| 产品合同 / visual-spec / 冻结设计图 | 设计真源页（如 Notion），仓内只放链接 |
| 测量/采样脚本 | **仓内**（真源页放脚本的仓内链接；脚本无法"同存"于 Notion） |
| 组件登记表 | 仓内（见 §3） |
| needs-backend 追踪 | 合同页内立项区，状态随进展更新 |
| 验收 montage / 截图证据 | gitignored 证据目录（设计图的验收用临时副本同样 gitignored，不算入仓） |
