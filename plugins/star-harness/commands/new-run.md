Follow `[[orchestrate-mission-waves]]` and the same behavior as
`/team:start`. Create or reuse a Mission-linked team, create a Mission-scoped
TeamRun, create or assign shared Works, and report exact returned ids and URL.
The command basename is compatibility-only; it does not create a Wave. Append a
Mission Log entry when the Host makes a material judgment or re-plan. Do not
create Assignment Messages; use TeamMessage only for conversation.
